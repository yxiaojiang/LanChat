# LanChat - 局域网极速快传与轻量聊天工具

一个专为 Windows 内网环境打造的**极轻量级（单文件仅约 46KB）**无服务器局域网通讯工具。支持文字聊天与任意二进制大文件的高速传输。

---

## 🌟 核心特性

- **极致轻量（~46KB）**：无任何第三方依赖库，无需安装任何运行库，直接双击运行。
- **纯内网 / 无服务器架构**：无需配置中心服务器或连接外网，全内网点对点（P2P）通信。
- **自动发现（广播组网）**：
  - 启动后自动通过 UDP 广播探测局域网内的其他成员。
  - 实时更新在线好友列表，显示对方昵称、主机名及 IP。
- **跨网段/VLAN 手动添加**：
  - 若公司交换机/路由器禁用了 UDP 广播或处于不同网段，支持点击【➕ 添加IP】进行精准定向探测与互联。
- **实时文字聊天**：
  - **局域网广播**：向全网所有在线成员发言。
  - **私人点对点会话**：点击左侧任意成员，即可进行 1 对 1 私聊。
  - 支持快捷键 `Enter` 发送消息，`Shift + Enter` 换行。
- **二进制文件极速互传**：
  - **支持任意格式**：ZIP压缩包、EXE可执行文件、视频、音频、ISO镜像、文档等。
  - **流式分块传输（64KB Chunk）**：无论文件是 1KB 还是 10GB+，均以极低内存占用流畅传输。
  - **拖拽即传（Drag & Drop）**：直接从 Windows 资源管理器将文件拖入聊天窗口即可直接发送。
  - **实时进度与测速**：显示百分比进度条与实时网络传输速率（MB/s）。
  - **自动接收与防重名**：默认自动保存至程序目录下的 `ReceivedFiles` 文件夹，重名文件自动编号防覆盖。

## 🚀 快速使用

### 1. 运行程序
在任意 Windows 7 / 8 / 10 / 11 电脑上，直接双击运行：
```
LanChat.exe
```

### 2. 使用方法
1. **修改昵称**：在顶部文本框输入你的昵称，点击【改名】即可同步广播至全网。
2. **文字聊天**：
   - 选中左侧【📢 局域网所有人 (广播群聊)】：发送的消息所有局域网电脑均可见。
   - 选中左侧具体好友（如【👤 张三】）：发送 1 对 1 私密消息。
3. **发送文件**：
   - **方式一（最快捷）**：直接从桌面或文件夹**将文件拖拽**进右侧聊天窗口。
   - **方式二**：点击聊天区底部的【📎 发送文件...】按钮选择文件。
4. **查看接收的文件**：
   - 点击顶部或底部的【📂 接收文件夹】，会自动在资源管理器中打开接收目录。

## 🛠️ 项目结构与重新编译

```
LanChat/
├── LanChat.exe           # 编译生成好的超轻量独立执行程序 (~46KB)
├── Program.cs            # 程序入口（高DPI支持与全局异常处理）
├── Models.cs             # 数据模型（PeerInfo、ChatMessage、FileTransferProgress）
├── NetworkService.cs     # 网络核心服务（UDP 广播发现、TCP 流式通信、文件流收发）
├── MainForm.cs           # 现代扁平化 WinForms 界面交互与拖拽响应
├── LanChat.csproj        # 现代 .NET 9 项目工程文件
├── build.bat             # 一键秒级重新编译脚本（调用系统自带 csc.exe）
└── README.md             # 使用说明文档
```

### 重新编译
双击运行目录下的 `build.bat` 即可在 1 秒内重新生成 `LanChat.exe`：
- 使用 Windows 自带的 C# 编译器（`csc.exe`），无需安装任何额外开发工具。
- 也可以使用 .NET CLI：`dotnet build -c Release`。

## 🔒 网络协议说明

| 功能 | 协议 | 默认端口 | 说明 |
| :--- | :--- | :--- | :--- |
| **节点发现与心跳** | UDP | 38888 | 广播包 `HELLO` / `ACK` / `PING` / `BYE`，启用端口复用 |
| **文字消息与文件传输** | TCP | 38889+ | 自动递增端口，流式二进制传输协议，支持大文件高速收发 |
