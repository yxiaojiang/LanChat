## 最近改动

1. **核心架构落地**：实现局域网通讯底座（UDP 38888 节点发现与网段探测、TCP 38889+ 双向即时文本消息与 64KB Chunk 分块文件流式传输）。
2. **攻克 TUN 代理隔离 BUG**：
   - 本机开启 sing-tun/Clash 等代理时，虚拟网卡抢占 Metric 0 默认路由导致物理局域网广播失效、TCP 源 IP 错乱。
   - 实现了虚拟网卡特征识别与过滤，为物理网卡独立绑定 UDP 套接字，并强制出站 TCP 连接显式绑定物理 LAN 接口，彻底绕过代理。
   - 引入局域网快速单播扫描与 TCP 握手探测（Subnet Sweep），绕开路由器对广播包的风暴抑制，实测 2 秒内捕获对端 `192.168.255.147`。
3. **消除 5 秒延迟（ThreadPool 饥饿优化）**：
   - 剖析定位到定时心跳误触发全网段 254 次阻塞连接将通用线程池塞满的问题。
   - 彻底解耦定时心跳与网段全量扫描，引入独立连接线程与即时消费机制，禁用 Nagle 算法（`NoDelay = true`），往返延迟由 ~5000ms 降至 5ms。
4. **UI 高 DPI 自适应与防换行**：重构 Windows 端顶部工具栏为 FlowLayout 弹性布局，充足扩充【🔄 刷新好友】等按钮宽度。
5. **打造全功能 Linux 端（双架构 + Python 通用版）**：
   - 构建 `LanChat.Linux`，交叉编译输出自包含 ELF 文件：`release/linux-x64/lanchat` 与 `release/linux-arm64/lanchat`。
   - 编写纯标准库单文件 `lanchat.py`，免安装任何依赖，支持交互式彩色终端会话与传输。
6. **项目工程化与代码托管**：配置 `.gitignore`，初始化 Git 并将全套代码推送至 `https://github.com/yxiaojiang/LanChat.git`。

## 风险与注意事项

1. **多网段/子网掩码非 /24 的情况**：当前单播扫描默认按 `/24`（255 个地址）高效并发；若处于超大局域网（如 `/16` 或 `/8`），不可盲目全量扫描，需依赖 UDP 广播或用户手动【添加 IP】。
2. **跨平台功能联动**：后续若在 Windows 客户端扩展新功能（如自定义协议头、富文本或状态机），必须同步检查 `lanchat.py` 与 `LanChat.Linux` 的兼容性，禁止私自变更魔数或破坏封包顺序。
3. **文件传输中断与并发控制**：当前支持单文件高速直传，若后续引入批量文件并行传输，需关注 Socket 连接数与磁盘 I/O 队列管控。
