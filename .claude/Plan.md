## LC-LINUX-002 · Linux Electron 桌面重构

### 第 3 步 · 对齐 Windows 界面与桌面操作（当前）

切片 1（主窗客户区：双栏、会话、聊天、文件卡片、暗色菜单、浮动滑块）代码审核已通过，见 [CRDocs](../CRDocs/STATUS.md)。下一步是切片 2：八个设置页。托盘、通知和维护入口尚未开始。证据见[集成记录](../PlanDocs/LC-LINUX-002/INTEGRATION.md)第 3 步切片。下面两项都还未通过。

- [ ] 按 Windows 基线清单实现双栏主界面、会话与聊天、文件卡片、弹层、八个设置页、维护入口和托盘／通知。逐项提供运行截图及操作证据，验证缩放、窄窗、中文输入法、焦点、长历史、浮动滑块和性能。
- [ ] 分别记录 Xorg、原生 Wayland、XWayland 的实际后端。托盘或通知不可用时保留窗口恢复入口和应用内未读。原生 Wayland 上自绘窗框不能完成规定窗口操作时切换系统边框，客户区继续对齐 Windows。

### 第 4 步 · 双架构正式候选验收

实机验收由用户执行，开发侧准备安装包、回退样本和可复跑回归，并按用户回传证据更新状态。

- [ ] 物理 x86_64 和物理 ARM64 各自完成实际旧包升级、回退、桌面／无头 CLI 与端口释放；分别与物理 Windows `v2.0.16` 在真实局域网验证发现、双向私聊和群聊、双向文件 SHA-256。
- [ ] 完成承诺的核心矩阵，包括原生 GNOME Wayland 和 Xorg、fcitx5 与 ibus、TUN、多网卡、无默认路由、`v2.0.15` 与公开旧 ELF 互通。承诺的实机格或核心回归缺少通过证据时，候选验收保持未通过；KDE 等未承诺组合单列未测。通过后复核 Windows 原生编译和构建摘要，再走[独立代码审核](../CRDocs/STATUS.md)。

Windows Electron 在 Linux 验收后另行评估。正式发布需用户另行授权。
