# GrokUI.md — GrokBot UI 全面设计规范与视觉对齐标准

详细设计规范已归档至 `Docs/GrokBot_UI_Design_System.md`。

## 核心设计契约
1. **暗黑分层**：
   - 侧边栏 `#0E0E0E`，主聊天视口 `#121212`，设置卡片 `#1C1C1F`，输入胶囊 `#202024`，悬停高亮 `#28282C`~`#2E2E34`。
   - 描边一律使用极细微光 `#2C2C32`，**坚决杜绝亮蓝/强发光外描边**。
2. **文字排版**：
   - 输入框文字与焦点文本：`11.0pt (15px)`，高饱和明亮白 `#F2F2F6`。
   - 窗口大标题：`18.0pt` Bold `#FFFFFF`。
   - 分组标签/辅助文字：`10.5pt` / `9.0pt`，中性灰 `#8E8E93`。
   - 占位符文本：`#5E5E66`。
3. **呼吸感与间距**：
   - 卡片内边距 `20px~24px`，设置行单行高度严格 `54px`。
   - 菜单项行高严格 `46px`。
4. **圆角与投影**：
   - 窗体与浮动菜单：`16px` 大圆角 + `CS_DROPSHADOW` 柔和投影。
   - 胶囊组件：`50%` 满圆角。
   - 悬停卡片：`8px` 圆角。
5. **严禁使用 OS 原生直角菜单或白底 MessageBox**：
   - 全盘使用 `GrokPopupMenu` 与 `GrokMessageBox`。
